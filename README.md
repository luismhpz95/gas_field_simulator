# Курсовая работа: Симулятор газового куста
**Дисциплина:** Алгоритмизация и программирование в решении задач разработки  
**Итоговый продукт:** работающий программный комплекс на Python + ноутбук с демонстрацией и анализом

# Описание проекта
Этот проект заключается в разработке численного симулятора для добычи природного газа на месторождении с тремя скважинами, работающими на один общий пласт. Симулятор моделирует поток газа от пласта до магистрального трубопровода.
